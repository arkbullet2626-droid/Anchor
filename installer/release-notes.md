**Anchor by Opifex Studios** — your windows stay anchored where you put them.

A tiny, free Windows tray app that puts your windows back where they belong after sleep, a monitor turning off and on, or a game changing resolution. Install it once and forget it.

### Download
**AnchorSetup.exe** below. Windows 10 (1809 or newer) or Windows 11, 64-bit. No admin needed to install.

Anchor isn't code-signed yet, so Windows may say "Windows protected your PC". Click **More info → Run anyway**.

### What's in 1.0
- Puts windows back automatically after sleep, unlocking, the screen waking, monitors turning off and on, and game resolution changes. No clicks needed.
- Recognises your monitors by model and serial, with a separate memory for each monitor setup and each resolution.
- Handles maximized, minimized and snapped windows, mixed scaling, and several windows of the same app.
- Waits while a fullscreen game is in front.
- Tray menu: Restore now, Save layout, Undo last restore, Pause, Settings.
- Starts with Windows. Optional admin mode to move windows of admin programs like Task Manager.
- Private: no account, no analytics. The only thing online is an optional daily update check.
